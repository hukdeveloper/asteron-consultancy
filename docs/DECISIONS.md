# Architecture Decision Log — Asteron Global Consultancy

This log tracks confirmed decisions, proposed decisions awaiting sign-off, and unresolved questions that require the lead architect's input. Entries should be updated in place (status changed) rather than duplicated when a decision resolves. Dates use ISO format (YYYY-MM-DD).

## How to Use This Log

- **Confirmed:** Decided and binding on implementation.
- **Proposed:** A recommendation has been made (usually in another doc) but not yet explicitly approved by the lead architect.
- **Unresolved:** A genuine business or technical choice with no default assumed; implementation should not proceed on an assumed answer without flagging it here first.
