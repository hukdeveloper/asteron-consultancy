# Visual Redesign Matrix

Status: **planning document only — no inner-page redesign has been implemented from this matrix yet.** It exists to satisfy the Phase A ("MANDATORY RESET") brief's explicit requirement to inventory every route and assign a template _before_ inner-page redesign begins, and to give the owner something concrete to approve or redirect ahead of that work. See [DECISIONS.md](DECISIONS.md) "Visual Language Reset" for the phase history.

## Templates

Every inner page is assigned exactly one of seven templates. A template is a shared visual pattern (hero treatment, body layout, image role), not a shared component — pages using the same template still carry their own content.

| Template                  | What it's for                                                                                                                            |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Destination editorial** | A single country's study-abroad page — long-form, image-led, narrative.                                                                  |
| **Service editorial**     | A single service/insurance/pathway page — what it is, who it's for, how it works.                                                        |
| **Collection-gallery**    | A hub page whose job is to route the visitor into one of several items (destinations, universities, resources, events, success stories). |
| **Resource-article**      | A single long-form content piece (a guide, an event, a resource).                                                                        |
| **Form journey**          | A page whose primary job is a form (consultation, eligibility, contact, insurance quote).                                                |
| **Corporate-about**       | About/Team — credibility and identity, not conversion.                                                                                   |
| **Legal-readable**        | Legal/reference text — narrow reading column, minimal decoration.                                                                        |

## Sequencing note

This matrix is ordered by template family for reference, not by build priority. When inner-page redesign is authorized, the owner should confirm priority order — the most visually load-bearing routes (destination pages and the services/insurance hubs, which share the most DOM with the just-replaced homepage sections) are the natural first candidates, since they can reuse the new `DestinationsSection`/`ServicesSection`/`InsuranceSection`/`ScholarshipSection` visual language directly rather than inventing new patterns.
