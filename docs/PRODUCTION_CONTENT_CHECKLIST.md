# Production Content Checklist — Asteron Global Consultancy (Phase 8)

Every placeholder, demo, template, or draft item currently in this codebase, classified by how much it blocks a real production launch. See README.md "Current Temporary Content" for the shorter, non-classified version of this same list, and [CLAUDE.md](../CLAUDE.md) "Content and Business-Claim Rules" for the policy these items follow (never present sample content as verified fact).

## Classification key

- **Blocker** — must be replaced with real, verified content/values before this site can go live for real users. Launching with this item unresolved would mean the public site makes a claim that isn't true, or collects/directs enquiries somewhere that doesn't reach the business.
- **Important** — should be resolved before launch if at all possible; launching without it is a known, visible gap but not a false claim.
- **Enhancement** — improves the site but its absence is not misleading and does not block a defensible launch.
- **Future integration** — depends on a later track (Track 2 form-service integration or Track 3 Strapi) and is out of scope for this track by design.

## Not a blocker (explicitly verified accurate as-is)

- **Cookie Policy** (`src/content/legal.ts`, `cookie-policy`): accurately states no analytics/advertising cookies or consent system exist today. No cookie banner is needed because nothing non-essential is set.
- **No fabricated statistics, awards, certifications, or partnerships** exist anywhere in the content — verified by `npm run validate:content` (`src/content/integrity.test.ts`) and each content type's own policy tests.
- **No company registration number, business license number, or regulatory registration is claimed anywhere** (verified in Phase 9 by full-text search) — nothing to correct; add one only once a real, verifiable number exists and the lead architect confirms it should be published.
- **Site URL** — see "Blockers" above (`NEXT_PUBLIC_SITE_URL`); the codebase itself is verified to have no hardcoded `localhost`/production-URL assumption — every canonical/OG/sitemap URL derives from this one variable (`src/lib/env.ts`), with a safe `http://localhost:3000` development-only fallback that never silently ships to production undetected (an unset variable is caught by this checklist's own blocker entry, not by a code-level check).
